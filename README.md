# PokéBot · Terms of Service website

A static, responsive website for GitHub Pages. No installation, build process, external fonts or packages are required. Open index.html to preview it locally. All paths work under a GitHub project repository URL.

## Publish on GitHub

1. Extract this ZIP on your computer.
2. Create a public GitHub repository (for example, pokebot-terms).
3. Upload the extracted website files to the repository root. Upload the files, not the ZIP or an enclosing folder. index.html must be at the root.
4. Open Settings → Pages. Under Source, select Deploy from a branch.
5. Select main and /(root), then Save. Wait for GitHub to report the deployed URL.
6. Your address normally looks like https://YOUR-USERNAME.github.io/pokebot-terms/ (use the actual URL GitHub provides).
7. Use that public URL as the Terms of Service URL for your Discord application.

GitHub documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
